# MemoVerse demo

An account is required — there is no guest mode. Before the demo, sign in once
(your browser keeps the session), or create an account on the spot with
**Continue with Google**, which needs no email confirmation.

1. Open MemoVerse and choose **Explore Memories**.
2. Sign in to show a saved journal entry, or choose **Try a Demo** for the sample room.
3. In My Journal, select a memory and choose **Create 3D world** or **Open 3D world**.
4. Explore the room. For a saved recording, use headphones to play or pause the personalized podcast.
5. Return to the journal and reopen the saved world to demonstrate reuse without another generation.

The sample room is explicitly labelled Sample. A new world uses a generation allowance;
reopening an existing world or recording does not. Check provider availability before a live demo.

Email-and-password sign-up sends a confirmation link, so use Google sign-in (or
an account created earlier) when time is short.
